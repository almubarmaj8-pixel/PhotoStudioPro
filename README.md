# 📸 PhotoStudio Pro

<div dir="rtl">

تطبيق أندرويد احترافي لتعديل الصور، مبني بـ **Kotlin** و **Material Design 3**، بواجهة عصرية ملونة جذابة.

## ✨ المميزات

### 🎨 فلاتر احترافية
- 12 فلتر جاهز: دافئ، بارد، كلاسيكي، أبيض وأسود، زاهي، باهت، درامي، بني داكن، نوار، غروب، غابة
- معاينة فورية لكل فلتر

### 🎛️ تعديلات دقيقة
- السطوع، التباين، التشبع، الدفء، الحدة
- شريط تمرير احترافي لكل تعديل

### ✏️ إضافة نص
- إضافة نص متعدد على الصورة
- تخصيص اللون والخط
- سحب وإفلات النص بسهولة
- ظل تلقائي للنص

### 😍 ملصقات وإيموجي
- 40+ رمز تعبيري وملصق
- سحب وإفلات على الصورة
- تصنيفات متنوعة: وجوه، نجوم، قلوب، طبيعة

### ✂️ اقتصاص وتدوير
- تدوير يمين/يسار
- قلب أفقي/رأسي
- نسب أبعاد متعددة: حر، مربع، 4:3، 3:4، 16:9، 9:16

### 📐 قوالب جاهزة
- منشور انستغرام، قصة، غلاف فيسبوك
- صورة يوتيوب، حالة واتساب، ملصق
- تكوين صور (Collage)

### 💾 حفظ ومشاركة
- حفظ بجودة عالية (95% JPEG)
- مشاركة مباشرة على جميع التطبيقات
- حفظ تلقائي في مجلد PhotoStudioPro

```
app/src/main/java/com/photostudio/pro/
├── PhotoStudioApp.kt              # Application class
├── ui/
│   ├── splash/                    # شاشة البداية
│   ├── main/                      # الشاشة الرئيسية (معرض + كاميرا + قوالب)

│   │   ├── EditorActivity.kt      # المنسّق الرئيسي للمحرر
│   │   ├── FilterType.kt          # تعريف الفلاتر (GPU + مصفوفة لونية للمعاينات)

│   │   ├── StickerAdapter.kt      # شبكة الملصقات
│   │   ├── EditorHistory.kt       # نظام التراجع/الإعادة
│   │   ├── OverlayItem.kt         # نموذج طبقات النص/الملصق (إحداثيات مطبّعة)
│   │   ├── OverlayDragController.kt # سحب/تصغير العناصر
│   │   ├── CropOverlayView.kt     # إطار الاقتصاص التفاعلي
│   │   ├── ImageExporter.kt       # تصدير بدقة الصورة الكاملة
│   │   └── ImageSaver.kt          # الحفظ عبر MediaStore
│   └── templates/                 # القوالب (فتح المحرر على لوحة قماش)
```

### 🏗️ تحسينات البنية (إعادة البناء)
- **خط عرض موحّد**: الفلتر + التعديلات تُدمج في مجموعة GPUImage واحدة للحفاظ على الجودة دون تدهور متكرر.
- **معاينات فلاتر حقيقية**: تُولَّد عبر `ColorMatrix` (مكافئ بصرياً لمسار GPU) بدلاً من الصورة الأصلية.
- **تراجع/إعادة فعلي**: لقطات حالة كاملة مع إدارة تدوير للذاكرة.
- **تصدير بدقة كاملة**: النصوص والملصقات تُرسم على الصورة الأصلية (وليس دقة الشاشة) عبر نموذج بيانات بإحداثيات مطبّعة.
- **كاميرا فعّالة**: التقاط عبر `TakePicture` + `FileProvider` وفتح النتيجة في المحرر.
- **اقتصاص تفاعلي**: إطار قابل للسحب والتصغير مع نسب أبعاد وتطبيق حقيقي.
- **تحميل آمن للذاكرة**: تصغير الصور الكبيرة (`inSampleSize`) وتحرير الـ bitmaps عند الإغلاق.
