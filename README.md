# 📸 PhotoStudio Pro

<div dir="rtl">

تطبيق أندرويد احترافي لتعديل الصور، مبني بـ **Kotlin** و **Material Design 3**، بواجهة عصرية ملونة جذابة.

## ✨ المميزات

### 🎨 فلاتر احترافية
- 12 فلتر جاهز: دافئ، بارد، كلاسيكي، أبيض وأسود، زاهي، باهت، درامي، بني داكن، نوار، غروب، غابة
- معاينة فورية لكل فلتر

### 🎛️ تعديلات دقيقة
- السطوع، التباين، التشبع، الدفء، الحدة
- شريط تمرير احترافي لكل تعديل

### ✏️ إضافة نص
- إضافة نص متعدد على الصورة
- تخصيص اللون والخط
- سحب وإفلات النص بسهولة
- ظل تلقائي للنص

### 😍 ملصقات وإيموجي
- 40+ رمز تعبيري وملصق
- سحب وإفلات على الصورة
- تصنيفات متنوعة: وجوه، نجوم، قلوب، طبيعة

### ✂️ اقتصاص وتدوير
- تدوير يمين/يسار
- قلب أفقي/رأسي
- نسب أبعاد متعددة: حر، مربع، 4:3، 3:4، 16:9، 9:16

### 📐 قوالب جاهزة
- منشور انستغرام، قصة، غلاف فيسبوك
- صورة يوتيوب، حالة واتساب، ملصق
- تكوين صور (Collage)

### 💾 حفظ ومشاركة
- حفظ بجودة عالية (95% JPEG)
- مشاركة مباشرة على جميع التطبيقات
- حفظ تلقائي في مجلد PhotoStudioPro

## 🎨 التصميم
- واجهة داكنة عصرية بألوان متدرجة جذابة
- Material Design 3
- بطاقات بزوايا دائرية
- تدرجات لونية: بنفسجي، وردي، برتقالي، تركواز
- رسوم متجهية (Vector) عالية الجودة

## 🛠️ التقنيات المستخدمة
| التقنية | الاستخدام |
|---------|----------|
| Kotlin | لغة البرمجة |
| Android SDK 34 | المنصة |
| Material Design 3 | تصميم الواجهات |
| GPUImage | معالجة الفلاتر |
| Glide | تحميل الصور |
| ViewBinding | ربط الواجهات |
| Coroutines | العمليات غير المتزامنة |

## 📁 بنية المشروع
```
app/src/main/java/com/photostudio/pro/
├── PhotoStudioApp.kt          # Application class
├── ui/
│   ├── splash/                 # شاشة البداية
│   ├── main/                   # الشاشة الرئيسية
│   ├── editor/                 # محرر الصور
│   │   ├── EditorActivity.kt
│   │   ├── FilterType.kt
│   │   ├── FilterAdapter.kt
│   │   ├── StickerAdapter.kt
│   │   └── ImageSaver.kt
│   └── templates/              # القوالب
```

## 🚀 طريقة التشغيل
1. افتح المشروع في Android Studio
2. انتظر تحميل Gradle
3. اضغط Run ▶️ لتشغيل التطبيق

## 📋 المتطلبات
- Android Studio Hedgehog (2023.1) أو أحدث
- JDK 17
- Android SDK 34
- Min SDK 24 (Android 7.0+)
